私有 RustDesk 远程桌面中转服务器全套搭建与客户端配置教程

作者: Avery | 分类: 自建生产服务 | 最后更新: 2026-11

TeamViewer 商业封杀频繁、向日葵免费版严重限速（几百Kbps甚至限帧到 15 FPS）、ToDesk 限制登录设备数量。开源的 RustDesk 凭借端到端 Ed25519 高强度加密、原生支持硬件编码加速，已成为 IT 运维和远程办公的最佳选择。本文详解如何利用一台海外低延迟 VPS 快速构建一套属于自己的私有远程中转集群。

一、 架构原理：HBBS 与 HBBR 分工

RustDesk 的自建服务由两个核心组件构成：

  • hbbs（ID 注册与打洞服务器）： 负责客户端注册、NAT 穿透打洞协商。如果两端处于良好网络环境下，两台电脑会直接建立 P2P 直连，不消耗服务器流量。
  • hbbr（Relay 数据中转服务器）： 当两端处于复杂的企业内网、对称型 NAT 无法 P2P 直连时，所有画面和控制数据会通过 hbbr 进行加密中转传输。

💡 为什么中转服务器网络质量决定一切？

很多朋友用普通的海外便宜机房自建中转，结果鼠标拖动依然卡顿、画面掉帧，这是因为晚高峰公网丢包率过高导致 TCP 不断重传。中转服务器不需要很高的硬件配置（单核 1GB 内存足矣），但**网络回程必须是直连精品线路（CN2 GIA / 软银 / 9929）**。

实机推荐： 搬瓦工（BandwagonHost）洛杉矶 DC6/DC9 机房（三网 CN2 GIA-E 线路，带宽最高达 2.5Gbps ~ 10Gbps），实测晚高峰中转丢包率低于 0.3%，延迟稳定在 130~150ms 之间，远程控制体验丝滑跟手。

二、 服务器端口与防火墙规则清单

在开始部署之前，务必确保服务器防火墙及主机商的安全组已放行以下端口（尤其是 21116 的 UDP，打洞全靠它）：

端口 协议类型 所属组件 用途说明
21115 TCP hbbs NAT 类型测试
21116 TCP + UDP hbbs 核心端口：TCP 用于连接协商，UDP 用于打洞心跳
21117 TCP hbbr 核心端口：中转数据传输
21118 / 21119 TCP hbbs / hbbr 网页客户端支持（可选） 
# 使用 UFW 一键放行必要端口
ufw allow 21115:21119/tcp
ufw allow 21116/udp
ufw reload

三、 使用 Docker Compose 快速部署中转服务

1. 安装 Docker 与 Compose 环境

# 自动化安装最新稳定版 Docker
curl -fsSL https://get.docker.com | bash
systemctl enable --now docker

# 安装 docker-compose-plugin (若系统未集成)
apt-get update && apt-get install -y docker-compose-plugin

2. 创建配置文件并拉起容器

# 创建专用目录
mkdir -p /opt/rustdesk && cd /opt/rustdesk

# 编写 docker-compose.yml (将 192.0.2.1 替换为你服务器的真实公网 IP)
cat > docker-compose.yml << 'EOF'
version: '3'

networks:
  rustdesk-net:
    external: false

services:
  hbbs:
    container_name: rustdesk-hbbs
    image: rustdesk/rustdesk-server:latest
    command: hbbs -r 192.0.2.1:21117 -k _
    volumes:
      - ./data:/root
    networks:
      - rustdesk-net
    ports:
      - 21115:21115
      - 21116:21116
      - 21116:21116/udp
      - 21118:21118
    restart: unless-stopped

  hbbr:
    container_name: rustdesk-hbbr
    image: rustdesk/rustdesk-server:latest
    command: hbbr -k _
    volumes:
      - ./data:/root
    networks:
      - rustdesk-net
    ports:
      - 21117:21117
      - 21119:21119
    restart: unless-stopped
EOF

# 启动容器
docker compose up -d
参数解析： 命令末尾添加的 -k _ 参数表示**强制开启 Key 认证**。这意味着只有填入了对应安全公钥的客户端才能使用你的中转服务器，彻底杜绝你的中转被公网其他人蹭流量！

3. 查看安全公钥（Key）

# 查看自动生成的 ed25519 公钥 (用于填入客户端)
cat /opt/rustdesk/data/id_ed25519.pub

四、 Windows / Mac 客户端配置实操

  1. 从 RustDesk 官方网站 下载对应操作系统的安装包。
  2. 打开客户端，点击左侧菜单的 设置（Settings） -> 网络（Network）。
  3. 点击 解锁网络设置（Unlock Network Settings），填写以下三项：
    • ID 服务器（ID Server）： 填写你的服务器公网 IP（例如 192.0.2.1）。
    • 中继服务器（Relay Server）： 填写你的服务器公网 IP，后接 :21117（例如 192.0.2.1:21117）。
    • Key： 粘贴刚才在终端里通过 cat /opt/rustdesk/data/id_ed25519.pub 获取到的一长串公钥字符串。
  4. 点击确定保存。回到主界面底部，看到状态显示绿色的 “就绪（Ready）”，即代表私有专属中转集群正式工作！
