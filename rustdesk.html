基于 Docker 快速搭建私有 RustDesk 远程桌面中转服务器

作者: Avery | 分类: 自建服务 | 日期: 2026-11

💡 为什么需要自建中转？
RustDesk 官方公共中转服务器由全球志愿者维护，高峰期时常出现连接排队或延迟飙升。自建专属中转（Relay Server）能彻底告别卡顿，实现 60 帧无延迟远程控制。

一、 服务器配置与网络要求

自建中转对服务器 CPU/内存要求极低（1核1G足够），但对网络延迟与丢包率有极高要求。建议优先选购具有优质回国路由（如双向 CN2 GIA / 软银）的机房实例。

测试主力机型： 搬瓦工（BandwagonHost）洛杉矶 CN2 GIA-E 节点，三网丢包率常年 < 0.5%，延迟极稳。

查看 BandwagonHost 推荐机型详情

二、 使用 Docker Compose 部署服务

创建 docker-compose.yml 文件：

version: '3'
services:
  hbbs:
    container_name: rustdesk-hbbs
    image: rustdesk/rustdesk-server:latest
    command: hbbs -r 你的公网IP:21117
    volumes:
      - ./data:/root
    ports:
      - 21115:21115
      - 21116:21116
      - 21116:21116/udp
      - 21118:21118
    restart: unless-stopped

  hbbr:
    container_name: rustdesk-hbbr
    image: rustdesk/rustdesk-server:latest
    command: hbbr
    volumes:
      - ./data:/root
    ports:
      - 21117:21117
      - 21119:21119
    restart: unless-stopped

三、 防火墙端口放行与公钥配置

# 防火墙需放行 TCP(21115-21119) 与 UDP(21116)
ufw allow 21115:21119/tcp
ufw allow 21116/udp

# 查看服务端加密公钥 (客户端填入 Key 项)
cat ./data/id_ed25519.pub
