Linux VPS 生产环境标准化运维与性能调优实战指南

作者: Avery Lau 分类: 系统运维 / 基础设施 更新日期: 2026-11 Linux Kernel 6.x Debian/Ubuntu Docker

在跨国网络环境及轻量级云服务器（VPS）的日常运维中，初始系统的合理配置对实例的安全性、跨国吞吐性能和资源利用率起着决定性作用。本文整理了一套开箱即用的生产环境基础配置清单，涵盖底层内核调优、系统安全加固及海外基础设施网络选型实录。

一、 底层 TCP 网络与拥塞控制算法调优（BBR）

跨国骨干网在高峰时段不可避免存在丢包和抖动。Linux 内核内置的 Google BBR 拥塞控制算法能大幅提升弱网/丢包环境下的带宽利用率：

# 1. 写入内核 TCP 拥塞控制参数
cat >> /etc/sysctl.conf << EOF
net.core.default_qdisc = fq
net.ipv4.tcp_congestion_control = bbr
net.ipv4.tcp_fastopen = 3
net.ipv4.tcp_rmem = 4096 87380 67108864
net.ipv4.tcp_wmem = 4096 65536 67108864
EOF

# 2. 使配置立即生效
sysctl -p

# 3. 校验 BBR 模块激活状态 (输出应包含 bbr)
sysctl net.ipv4.tcp_congestion_control

二、 服务器安全基线与 SSH 访问控制

公网开放的服务器极易受到 22 端口暴力破解扫描。建议在实例交付的第一时间完成端口替换及仅允许公钥登录：

# 调整 SSH 安全配置
sed -i 's/#Port 22/Port 2222/' /etc/ssh/sshd_config
sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
sed -i 's/PermitRootLogin yes/PermitRootLogin prohibit-password/' /etc/ssh/sshd_config

# 配置 UFW 防火墙基础放行规则
ufw default deny incoming
ufw default allow outgoing
ufw allow 2222/tcp comment 'Custom SSH'
ufw allow 80/tcp comment 'HTTP'
ufw allow 443/tcp comment 'HTTPS'
ufw enable

# 重载 SSHD 守护进程
systemctl restart sshd

三、 轻量级虚拟内存交换区（Swap）配置

对于 1GB - 2GB 内存的云主机，配置 2GB 的应急 Swap 空间能够极大避免 MySQL 等重度进程因内存突发消耗导致 OOM（Out of Memory）进程被系统强杀：

# 创建并启用 2GB 交换分区
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile

# 持久化挂载
echo '/swapfile none swap sw 0 0' >> /etc/fstab

# 设置合理的 swappiness (建议 10~20，降低磁盘频繁读写)
echo 'vm.swappiness = 15' >> /etc/sysctl.conf && sysctl -p
