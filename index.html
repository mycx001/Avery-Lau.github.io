一、 Linux 快速上手与常用日常排障命令

对于初次接触 Linux 服务器的开发者，熟练掌握以下核心命令可迅速定位 90% 以上的资源与网络异常：

1. 系统资源与负载监控

# 查看实时 CPU、内存占用与进程树 (建议使用 htop，如无可通过 apt install htop 安装)
htop

# 查看磁盘空间占用与挂载情况 (-h 表示人类可读单位如 GB/MB)
df -h

# 查看当前内存及虚拟内存（Swap）使用情况
free -m

2. 网络连接与端口监听排查

# 查看当前系统正在监听的 TCP/UDP 端口及对应进程 PID
ss -tulpn

# 快速检测本机到外部目标主机的延迟与路由追踪
mtr -rw [目标IP]

二、 底层 TCP 拥塞控制调优（开启 Google BBR）

跨国骨干网络在晚高峰常出现突发丢包。开启 Linux 原生集成的 BBR 算法，能在高延迟丢包环境下保证较高的传输吞吐率：

# 写入内核网络调优参数
cat >> /etc/sysctl.conf << EOF
net.core.default_qdisc = fq
net.ipv4.tcp_congestion_control = bbr
EOF

# 使配置立即生效并检验
sysctl -p
sysctl net.ipv4.tcp_congestion_control
# 输出显示 net.ipv4.tcp_congestion_control = bbr 即代表生效

三、 搭建属于自己的私有 RustDesk 远程桌面中转服务器

TeamViewer、ToDesk 等商业远程软件往往有设备数量限制或网络高峰拥堵。采用开源的 RustDesk 自建中转服务器，可以实现端到端加密、高画质且无限制的流畅远程办公。

💡 服务器网络选型建议：
RustDesk 远程控制与画质传输对**丢包率和往返延迟（RTT）**极度敏感。如果中转服务器网络较差，鼠标会出现明显的漂移和卡顿。实测推荐使用三网回程优质直连（如 CN2 GIA / 软银 / 9929）的云主机作为中转节点。

1. 使用 Docker Compose 一键启动中转服务（hbbs / hbbr）

在服务器新建 docker-compose.yml 文件：

version: '3'

networks:
  rustdesk-net:
    external: false

services:
  hbbs:
    container_name: rustdesk-hbbs
    ports:
      - 21115:21115
      - 21116:21116
      - 21116:21116/udp
      - 21118:21118
    image: rustdesk/rustdesk-server:latest
    command: hbbs -r 你的服务器公网IP:21117
    volumes:
      - ./data:/root
    networks:
      - rustdesk-net
    restart: unless-stopped

  hbbr:
    container_name: rustdesk-hbbr
    ports:
      - 21117:21117
      - 21119:21119
    image: rustdesk/rustdesk-server:latest
    command: hbbr
    volumes:
      - ./data:/root
    networks:
      - rustdesk-net
    restart: unless-stopped

2. 启动服务与获取加密公钥 Key

# 后台拉起中转容器
docker compose up -d

# 查看生成的安全验证公钥（Key），客户端配置时需填入
cat ./data/id_ed25519.pub

四、 常用云主机与网络链路选型实测

在进行远程中转、后端 API 交互或企业跨国部署时，机房线路的物理路由决定了最终体验：

线路类型 承载骨干网 高峰期丢包表现 推荐应用场景
电信 CN2 GIA (AS4809) 中国电信高端政企专网 极低 (< 0.5%) 核心业务、RustDesk 中转、关键生产服务
联通 AS9929 / 移动 CMIN2 联通A网 / 移动精品网 优秀 (< 1%) 多运营商混合接入、跨国数据同步
普通 163 骨干直连 民用普通互联链路 晚高峰波动大 (10%~20%) 离线冷备份、海外本地服务
