Linux 小白入门避坑指南与生产环境运维速查手册

作者: Avery | 分类: Linux 零基础教程 | 最后更新: 2026-11

写在前面： 刚买完海外 VPS 的很多新手朋友面对黑乎乎的终端窗口往往无从下手。本文从最基础的连接工具、文件操作、权限机制到日常排错，梳理一份真正通俗易懂的实战笔记，拒绝晦涩难懂的理论。

一、 远程连接与基础交互认知

云服务器本质上是一台没有显示器的远程电脑，你只能通过 SSH（Secure Shell） 协议在本地终端操作它。

  • Windows 推荐连接工具： Windows 10/11 自带 PowerShell、Tabby、FinalShell、MobaXterm。
  • Mac / Linux： 直接打开自带的“终端（Terminal）”即可。

1. 最基础的 SSH 登录命令

# 语法：ssh 用户名@服务器公网IP -p 端口 (默认端口22)
ssh root@192.0.2.1

# 如果主机商分配了非标准端口（如 28888）：
ssh root@192.0.2.1 -p 28888
⚠️ 避坑提醒： 在终端输入密码时，屏幕上不会显示任何星号或占位符（这是 Linux 的密码隐身保护机制），直接敲完密码敲回车，或者在终端右键粘贴即可。

二、 必须牢记的日常高频核心命令

1. 目录穿梭与文件管理

命令 作用说明 实际使用示例
pwd Print Working Directory：显示当前所处的绝对路径 pwd
ls -lh 列出当前目录下的文件，并以友好格式（MB/GB）显示大小 ls -lh /var/log
cd 切换目录（Change Directory） cd /etc/nginx（回根目录：cd /，回用户家目录：cd ~）
mkdir -p 创建文件夹（-p 允许递归创建多层目录） mkdir -p /data/docker/myproject
cp -r 复制文件或整个文件夹 cp -r source/ backup/
mv 移动文件，或者给文件重命名 mv old.conf new.conf
rm -rf 危险命令：强制删除文件或非空文件夹 rm -rf /tmp/cache/（千万别在根目录乱敲）

2. 查看文件内容（拒绝打开大文件卡死）

# 查看小型配置文件全部内容
cat /etc/issue

# 动态实时监控日志更新（运维抓 Bug 最常用命令）
tail -f -n 100 /var/log/nginx/access.log

# 分页浏览大型文件（按 Q 退出）
less /var/log/syslog

三、 Linux 用户权限与 chmod / chown 揭秘

很多小白经常遇到 Permission denied（权限拒绝）错误，这是因为 Linux 拥有极其严格的权限隔离模型：

  • 用户角色： 所有者（User/u）、所属用户组（Group/g）、其他所有人（Others/o）。
  • 权限数字含义： 读取(r)=4，写入(w)=2，执行(x)=1。相加即为对应权限数字：
    • chmod 755 filename：所有者拥有全部读写执行权限（4+2+1=7），其他人只能读取和执行（4+1=5）。
    • chmod 600 id_rsa：仅所有者拥有读写权限（私钥文件的标准权限）。

四、 服务器资源排障“三板斧”

当你的网站打不开、或者感觉服务器变慢时，按顺序敲以下三组命令，99% 的问题一目了然：

1. 第一斧：查 CPU 与内存死锁（看 htop / free）

# 检查内存与 Swap 占用情况（-m 表示按 MB 显示）
free -m
# 如果 available（可用内存）只剩几十兆，说明程序即将发生 OOM 内存溢出。

# 动态任务管理器，查看是哪个进程在疯狂占用 CPU
htop
# 按 F9 可以终止进程，按 F10 退出。

2. 第二斧：查磁盘是否被日志撑爆（df -h）

# 检查各磁盘分区空间
df -h
# 重点看挂载点为 "/" 的分区 Use% 是否达到 100%。如果满了，系统将无法创建临时文件导致崩溃。

3. 第三斧：查网络端口到底开没开（ss / netstat）

# 查看当前机器正在监听的服务和端口
ss -tulpn
# 检查你启动的服务（例如 80、443、21116）是否显示在 LISTEN 状态下。

五、 基础防火墙与网络调优

# Ubuntu / Debian 常用防火墙 UFW 快速管理
ufw allow 22/tcp    # 必须先放行 SSH，否则会被关在门外！
ufw allow 80/tcp    # 放行 HTTP
ufw allow 443/tcp   # 放行 HTTPS
ufw enable          # 启动防火墙
ufw status          # 查看规则清单

# 开启 TCP BBR 加速提升网络传输稳定性
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p
