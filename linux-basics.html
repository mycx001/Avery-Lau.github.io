Linux 云服务器生产环境安全加固与基础排障清单

作者: Avery | 分类: Linux 运维 | 日期: 2026-10

一、 开启 Google BBR 内核网络加速

通过优化 TCP 拥塞控制算法显著提升网络吞吐：

echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p

二、 日常性能与网络状态快速排查

# 1. 查看内存占用
free -h

# 2. 检查磁盘根分区剩余空间
df -h

# 3. 查看当前系统网络端口监听详情
ss -tulnp
